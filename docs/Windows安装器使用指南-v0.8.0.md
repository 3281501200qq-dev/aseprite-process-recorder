# Aseprite 绘画过程记录器 v0.8.0

适用系统：Windows 10/11 x64。

本版本提供一个标准 Windows 安装程序，自动部署 Aseprite 插件和独立 FFmpeg。用户不需要另外下载、解压或配置 FFmpeg。

## 一、v0.8.0 主要更新

- 新增完整、自动、性能三种记录模式。
- 新安装默认使用自动模式。
- 自动和性能模式不再对每个密集变化事件执行整画布合成，而是在很短的时间窗口内合并事件后再采集，降低大画布和长时间记录的绘画负载。
- 自动模式对总像素不超过 65,536（相当于 256×256）的画布保持逐变化记录，优先保留快速像素画细节。
- 停止记录、切换模式时会先补录最后待处理画面，保证最终画面完整。
- 保持“插件 + 独立 FFmpeg”的安装结构，FFmpeg 不放入 Aseprite 插件目录。

## 二、三种记录模式

### 自动模式（推荐）

新安装的默认模式。

- 总像素不超过 65,536：每次有效画面变化都记录，不进行时间合并。
- 65,537–262,144 像素：最多约每 50 毫秒采集一次密集变化。
- 262,145–1,048,576 像素：最多约每 100 毫秒采集一次密集变化。
- 超过 1,048,576 像素：最多约每 150 毫秒采集一次密集变化。

这里的“合并”只针对短时间内连续到来的密集事件，不是旧版“每 N 次变化抽一帧”。变化之间有足够间隔时仍会分别记录。

### 完整模式

每次有效画面变化都执行采集，细节最多。适合小画布、需要完整操作轨迹的情况；大画布或长时间绘制时，CPU、内存带宽和磁盘压力最高。

### 性能模式

适合大画布、长时间记录或性能余量较小的电脑。

- 总像素不超过 65,536：最多约每 50 毫秒采集一次密集变化。
- 65,537–262,144 像素：最多约每 100 毫秒采集一次密集变化。
- 262,145–1,048,576 像素：最多约每 180 毫秒采集一次密集变化。
- 超过 1,048,576 像素：最多约每 250 毫秒采集一次密集变化。

性能模式可能省略持续时间极短的中间状态，但停止时始终补录最终画面。如果快速小画布过程细节最重要，请使用自动或完整模式。

## 三、安装和组件结构

安装程序包含两个独立组件：

1. Aseprite 绘画过程记录器插件。
2. Gyan.dev FFmpeg `2026-08-06-git-95c43d7df7-essentials_build`，包含 `libx264`。

默认安装位置：

```text
插件：
%APPDATA%\Aseprite\extensions\aseprite-process-recorder

FFmpeg：
%LOCALAPPDATA%\Programs\Aseprite Process Recorder\FFmpeg\ffmpeg.exe
```

安装步骤：

1. 保存所有正在编辑的文件并完全退出 Aseprite。
2. 双击 `aseprite-process-recorder-0.8.0-windows-x64-cn-setup.exe`。
3. 阅读许可说明并完成安装。
4. 重新启动 Aseprite。

安装程序按当前用户安装，通常不需要管理员权限。若检测到 `Aseprite.exe` 正在运行，安装程序会要求先关闭，不会强制结束进程。

## 四、升级和偏好迁移

从旧版升级时：

- 旧“每次变化”模式迁移为完整模式。
- 旧“间隔记录”模式迁移为性能模式，保留旧用户偏向低负载的选择。
- 没有旧模式偏好的新安装使用自动模式。
- 保留播放速度、内存预算、视频放大设置和有效的自定义 FFmpeg 路径。
- 保留全部原图、差分日志、过程文件和 MP4。

旧版“每 N 次变化记录一帧”的间隔数不再显示；v0.8.0 改用按画布规模分级的时间合并。旧记录文件仍可继续读取和导出。

## 五、默认预设

- 记录模式：自动模式。
- 播放速度：1 倍。
- 内存预算：256 MB。
- 视频放大：自动安全放大。
- 视频帧率：30 FPS。
- 视频编码：H.264 MP4，`libx264`、`veryfast`、CRF 18。

记录默认保存在：

```text
文档\Aseprite Process Recordings
```

## 六、导出 MP4

1. 打开对应的原始 `.aseprite` 文件。
2. 选择“精灵 → 绘画过程记录器 → 导出紧凑 MP4”。
3. 等待导出完成。

插件直接读取磁盘差分日志，逐帧重建并流式交给独立 FFmpeg，不生成 PNG/JPG 图片序列，也不需要打开可能很大的 `_timelapse.aseprite` 文件。

绘画记录阶段不运行 FFmpeg。FFmpeg 只在导出 MP4 时启动，因此其独立安装方式不会增加绘画时的记录负载。

## 七、性能验证

在 Aseprite 1.3.18.2 x64 中完成以下批处理验证：

- 64×64 自动模式：初始画面加 12 次变化共 13 帧，未合并变化。
- 512×512 自动模式：20 次连续密集变化合并为一次采集；停止后的最终画面逐像素一致。
- 64×64 性能模式：20 次连续密集变化被合并；停止后的最终画面逐像素一致。
- 512×512 自动模式下，8 次人为分隔的变化保留为 8 次独立采集。

同机 512×512、200 次连续密集变化的合成基准中：

| 模式 | 记录循环耗时 | 会话帧数 | 差分数据量 |
| --- | ---: | ---: | ---: |
| 完整 | 732 ms | 201 | 84,767 字节 |
| 自动 | 257 ms | 2 | 13,457 字节 |
| 性能 | 274 ms | 2 | 13,457 字节 |

该基准用于验证密集事件合并确实减少整画布采集和写盘，不代表所有电脑或真实绘画都能得到相同比例。三组最终画面均逐像素一致。

## 八、卸载和许可

Windows“设置 → 应用 → 已安装的应用”中可卸载“Aseprite 绘画过程记录器”。卸载会删除本安装器部署的插件、FFmpeg 和许可说明，不会删除：

- `文档\Aseprite Process Recordings` 中的记录和视频。
- 原始绘画文件。
- Aseprite 的其他扩展和设置。
- Aseprite 已生成的插件偏好文件。

插件代码使用 MIT License。FFmpeg 作为独立 GPLv3 第三方程序运行，安装目录包含 GPLv3 全文、原始构建 README、确切源码提交和构建来源说明。

安装程序未进行代码签名。Windows SmartScreen 可能显示“未知发布者”，请先核对发布方提供的 SHA-256。
