Aseprite 制作過程レコーダー v0.8.3
=================================

この Windows インストーラーには、別々の 2 つの部品が含まれます。

1. Aseprite 制作過程レコーダー拡張機能
   インストール先：%APPDATA%\Aseprite\extensions\aseprite-process-recorder

2. FFmpeg 2026-08-06 essentials build（libx264 同梱）
   インストール先：%LOCALAPPDATA%\Programs\Aseprite Process Recorder\FFmpeg

インストール前に Aseprite を完全に終了してください。インストール後は
Aseprite を再起動してください。初期設定では、キャンバスを開くか
切り替えると自動的に録画が始まります。メニューで自動録画を継続的に
無効化しても、手動録画は利用できます。FFmpeg は自動でインストールされ、
MP4 の書き出し時にだけ実行されます。

録画モードは完全・自動・高性能の 3 種類です。完全モードは画面の変更を
すべて記録します。自動モードは 65,536 ピクセル以下の小さい画像では
変更ごとに記録し、大きい画像では短時間の連続操作を統合します。
高性能モードはより多くの操作を統合し、大きい画像や長時間の録画で
負荷を抑えます。自動・高性能モードでは停止時に最終画像を記録します。

メニューの「Language / 语言 / 言語」、またはレコーダー設定で
簡体字中国語・英語・日本語を選択できます。通知はすぐに切り替わります。
メニューの表示を更新するには Aseprite を再起動してください。

Windows で録画を停止すると、制作過程ファイルはバックグラウンドで
生成されます。完了までログと管理ファイルを保持してください。MP4 の
書き出しは完了まで待機します。大きい画像では取り込みや保存時に
一時停止が発生する場合があります。

アップグレード時には拡張機能の設定と
Documents\Aseprite Process Recordings 内の録画・動画を保持します。
アンインストール時には拡張機能と同梱 FFmpeg を削除しますが、
作品・動画・録画ファイルは削除しません。

FFmpeg は別個の GPLv3 ライセンスの第三者製ソフトウェアです。
ライセンス、ビルド情報、正確なソースコードのリビジョンを同梱します。
