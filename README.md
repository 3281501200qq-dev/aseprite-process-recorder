# Aseprite 绘画过程记录器

面向 Windows x64 的 Aseprite 绘画过程记录器。它自动记录可见画面变化，用磁盘差分日志保存过程，并可直接导出 Aseprite 过程文件与 H.264 MP4。

当前版本：`v0.8.0`

## 主要特点

- **三种录制模式**：完整、自动、性能。
- **小画布细节优先**：自动模式下，总像素不超过 65,536（相当于 256×256）的画布逐变化记录。
- **大画布密集事件合并**：中大型画布只合并很短时间内连续到来的事件，减少逐事件整画布合成压力。
- **磁盘差分日志**：按 64×64 图块比较，只写入变化图块，并在 RLE 与原始像素之间选择更小的编码。
- **不生成 PNG/JPG 序列**：原生 helper 逐帧重建后，通过 RGBA 管道流式交给 FFmpeg。
- **可继续记录**：清单和分段日志支持在同一源文件上续录，并保留真实事件时间戳。
- **长记录分卷**：过程文件可按帧数和体积拆分，避免单个超大 `.aseprite` 文件。
- **中文路径验证**：中文目录、中文源文件名、中文 MP4 文件名均完成端到端测试。
- **单文件安装器**：自动安装插件和独立 FFmpeg，用户不需要另行下载或配置。

## 与常见 Aseprite 延时录制插件的区别

这个项目不是简单地“每次变化另存一张图”，也不是把全部完整帧长期留在 Lua 内存中。核心区别是：

| 方面 | 本项目 | 常见实现方式 |
| --- | --- | --- |
| 采集策略 | 完整 / 自动 / 性能三档；自动模式按画布规模限频 | 每次变化固定截图，或固定间隔抽帧 |
| 小像素画 | 自动模式下 ≤65,536 像素逐变化记录 | 固定限频可能丢失快速中间状态 |
| 录制存储 | 64×64 图块差分日志，增量写盘 | PNG 序列、完整 `.aseprite` 帧或内存中的完整 Image |
| 视频导出 | 差分日志流式重建，直接传给独立 FFmpeg | 先生成图片序列，或要求用户自行安装 FFmpeg |
| 长时间记录 | 分段日志、检查点、内存预算、过程文件分卷 | 记录越久，图片数量、内存或单文件体积持续增长 |
| 时间信息 | 保存变化的真实时间戳，可在 1/2/5/10 倍之间重定时 | 常见为固定 FPS 回放 |
| Windows 安装 | 单个安装器部署插件和独立 FFmpeg | `.aseprite-extension` 与 FFmpeg 分开安装/配置 |

更具体、带参考项目链接的对照见 [docs/COMPARISON.md](docs/COMPARISON.md)。这里比较的是公开实现的架构和默认体验，不表示本项目在所有场景都优于其他项目。

## 下载与安装

1. 从 [Releases](https://github.com/3281501200qq-dev/aseprite-process-recorder/releases/latest) 下载 `aseprite-process-recorder-0.8.0-windows-x64-cn-setup.exe`。
2. 保存工作并完全退出 Aseprite。
3. 运行安装器，完成后重新启动 Aseprite。

默认安装位置：

```text
插件：%APPDATA%\Aseprite\extensions\aseprite-process-recorder
FFmpeg：%LOCALAPPDATA%\Programs\Aseprite Process Recorder\FFmpeg\ffmpeg.exe
```

FFmpeg 不在插件目录中，也不会在绘画录制阶段运行；它只在导出 MP4 时作为独立进程启动。

完整说明见 [Windows 安装器使用指南](docs/Windows安装器使用指南-v0.8.0.md)。

## 三种录制模式

- **自动模式（推荐）**：小画布逐变化；中大型画布按 50–150ms 窗口合并密集事件。
- **完整模式**：每次有效画面变化都采集，细节最多，负载最高。
- **性能模式**：按 50–250ms 窗口更积极地合并密集事件，适合大图和长时间记录。

自动和性能模式停止时都会补录最终画面。性能模式可能省略持续时间极短的中间状态。

## v0.8.0 验证结果

测试环境：Aseprite 1.3.18.2 x64，Windows 11 x64。

- 64×64 自动模式：初始画面 + 12 次变化 = 13 帧，没有合并。
- 512×512 自动模式：20 次连续密集变化合并为一次采集，最终画面逐像素一致。
- 512×512 自动模式：8 次人为分隔的变化保留为 8 次独立采集。
- 中文路径下完成 28 帧 H.264 MP4 导出，并由 FFmpeg 完整解码，退出码为 0。

同机 512×512、200 次连续密集变化的合成基准：

| 模式 | 记录循环耗时 | 会话帧数 | 差分数据量 |
| --- | ---: | ---: | ---: |
| 完整 | 732 ms | 201 | 84,767 字节 |
| 自动 | 257 ms | 2 | 13,457 字节 |
| 性能 | 274 ms | 2 | 13,457 字节 |

该基准验证的是密集事件合并是否减少采集和写盘，不代表真实绘画一定获得相同比例。

## 源码与构建

- `plugin/`：Aseprite Lua 插件、Windows helper 和 zlib 许可。
- `installer/`：Inno Setup 安装脚本、FFmpeg 构建说明及第三方许可。
- `tests/`：模式行为测试和合成基准。

Windows helper 当前以预编译二进制随仓库和安装器发布；Lua 插件和安装脚本源码已公开。构建正式安装器的方法见 [BUILDING.md](BUILDING.md)。
