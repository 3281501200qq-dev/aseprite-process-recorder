# Aseprite 制作過程レコーダー

[简体中文](README.md) · [English](README.en.md)

現在のバージョン：`v0.8.3`。Windows x64 向けの拡張機能です。画面の変化を記録し、Aseprite の制作過程ファイルまたは H.264 MP4 動画として書き出せます。

## 主な特徴

- 録画モードは 3 種類です。完全モードは画面の変更をすべて記録します。自動モードは 65,536 ピクセル以下の画像で変更ごとに記録し、大きい画像では短時間の連続操作を統合します。高性能モードは大きい画像や長時間の録画向けにさらに多くの操作を統合します。
- 64×64 ピクセル単位の差分をディスクに記録するため、すべてのフレームをメモリに保持したり、PNG 画像列を生成したりしません。
- 専用プログラムがフレームを復元し、独立した FFmpeg プロセスへ動画データを送ります。FFmpeg は MP4 の書き出し時のみ動作します。
- ログの分割、チェックポイント、メモリ上限の設定、制作過程ファイルの分割に対応します。
- 実際の変更時刻を保存し、再生速度を 1・2・5・10 倍から選べます。
- Windows では、録画停止後の制作過程ファイル生成はバックグラウンドで行います。MP4 の書き出しは完了まで待機します。
- 一つのインストーラーで拡張機能と FFmpeg を導入できます。

自動・高性能モードは停止時に最終画像を記録します。高性能モードでは一瞬だけ表示された中間状態が省略される場合があります。すべての変更を残したい場合は完全モードを選んでください。

## インストール

[Releases](https://github.com/3281501200qq-dev/aseprite-process-recorder/releases/latest) から `aseprite-process-recorder-0.8.3-windows-x64-multilingual-setup.exe` をダウンロードしてください。Aseprite を完全に終了してインストーラーを実行し、インストール後に Aseprite を再起動します。`.aseprite-extension` は拡張機能のみで、FFmpeg は含まれません。

拡張機能の場所：`%APPDATA%\Aseprite\extensions\aseprite-process-recorder`。FFmpeg の場所：`%LOCALAPPDATA%\Programs\Aseprite Process Recorder\FFmpeg`。

## 言語と自動録画

メニューの **制作過程レコーダー → Language / 语言 / 言語** または設定画面で簡体字中国語・英語・日本語を選べます。設定は保存されます。通知はすぐに切り替わり、メニューの表示は Aseprite を再起動すると更新されます。新規インストールの初期言語は簡体字中国語です。

初期設定では、キャンバスを開くか切り替えると録画を開始します。メニューで自動録画を継続的に無効化しても、手動録画は利用できます。更新・アンインストール時に作品、録画、動画は削除されません。
